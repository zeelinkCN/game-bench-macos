# 拾光游戏厅 · Game Bench

本地运行的 Apple Silicon Mac 复古游戏平台。双击
`build/拾光游戏厅.app` 即可使用，不需要安装 Node、浏览器插件或另一个模拟器。

## 私有仓库结构

- `zeelinkCN/game-bench-macos`：平台源码、构建脚本、测试和许可，不包含游戏 ROM。
- `zeelinkCN/game-bench-library`：独立私有游戏资源库，包含目录、ROM、封面和来源记录。

把两个仓库克隆为相邻目录即可构建；也可用 `GAMEBENCH_LIBRARY_DIR` 指定资源库路径。

如果只构建客户端、不内置任何 ROM，可使用 `GAMEBENCH_THIN_BUILD=1 scripts/build.sh`。轻量版会从“游戏市场”读取独立资源仓库的目录，支持按单款或按系列安装；资源仓库保持 Private 时会使用本机已登录的 GitHub CLI，改成 Public 后直接通过 HTTPS 获取。
新增游戏只更新资源仓库及其目录，不需要把大型二进制资源提交到平台源码历史。

当前游戏库来自用户明确授权的两个自有备份仓库，按 SHA-256 内容指纹跨仓库
去重；另有自制双人试玩 **星光试航 / Star Pilot**。原先的 100 款社区自制
游戏已从成品移除。每款内置游戏的名称、来源和 SHA-256 均保存在
资源仓库的 `catalog.json` 保存游戏目录，`sources.json` 保存仓库提交、输入和
去重统计，游戏卡片右键可查看来源。

当前 1131 款游戏全部有封面：368 款恢复自旧站编号清单，755 款由实际 ROM
自动启动并抓取有效画面，7 款使用同一作品其他版本的旧封面，1 款使用明确
标注的本地标题卡。旧站 2324 张编号图片和恢复后的映射表均保存在资源仓库。

自动启动检查中 1118／1131 款在 600 帧内或模拟按下 Start 后输出有效画面；
其余 13 个备份仍保留，并在卡片上标为「兼容性待验证」，不放入首页精选。

游戏库现在使用中文译名显示，保留英文原名供搜索。中文译名不代表游戏内部
文本已经汉化；每款卡片单独显示语言状态。「中文版本」筛选和设置里的「优先
排列中文游戏版本」按照版本标识工作。仅凭文件名识别的汉化版会明确标为未校验。

左侧「童年经典」参考中文怀旧文章和玩家回忆，把超级玛丽、魂斗罗、赤色要塞、
雪人兄弟、坦克大战、松鼠大作战、双截龙、热血系列、冒险岛等代表作放在首页
最前面。经典系列另列魂斗罗和超级玛丽并按版本整理；其他版本仍可搜索和游玩。

已核对 Jixun 的 FC 魂斗罗汉化发布和超级玛丽 3 汉化发布信息，系列页提供
来源链接。随附的 `Resources/Translations/ContraNES1TranslationPatch-source.zip`
是作者发布的汉化代码，不是可独立运行的游戏。仓库中现有的魂斗罗、超级玛丽
版本会自动归入系列页；无法从文件名确定的版本仍可通过右键手动调整。

卡片右键「应用 IPS 汉化补丁」可以对已导入的游戏应用补丁，生成独立副本，
保留原版和原存档。需要与补丁发布说明一致的基础 ROM；IPS 本身不记录原版
校验值，应用完成后仍需启动检查文字和画面，不能仅凭成功打补丁认定汉化正确。

- 红白机：`.nes` / `.fds`，FCEUmm 核心。磁碟机游戏需要 `BIOS/disksys.rom`。
- 超级任天堂：`.sfc` / `.smc`，Snes9x 核心。
- Game Boy / Color：`.gb` / `.gbc`，Gambatte 核心。
- 世嘉：`.md` / `.gen` / `.bin` / `.sms` / `.gg`，Genesis Plus GX 核心。
- 街机：FBNeo 对应 ROM 版本的 `.zip`；克隆版可能需要父 ROM，部分游戏需要 BIOS。
- 包含单个主机 ROM 的 ZIP 可直接导入；多游戏 ZIP 请先解压。
- 支持搜索、平台分类、收藏、最近游玩、内容去重以及子文件夹扫描。

## 操作

| 功能 | 操作 |
| --- | --- |
| 游戏库 | 方向键 / 左摇杆选择，手柄 A 启动，X 收藏，Y 测试手柄 |
| 标题画面 | 进入游戏后第一次按 Xbox A 会自动发送一次 Start；Menu（≡）始终是 Start |
| 全屏 | 游戏右上角全屏按钮，或 Control + Command + F |
| 暂停菜单 | Esc，或同时按 LB + RB |
| 暂停菜单中的手柄 | A 继续、B 返回游戏库、X 保存、Y 读档 |
| 手动存档 / 读档 | Command + S / Command + L |
| 投币 / 选择 | 手柄 View；1P 键盘 Shift；2P 键盘 R |
| 开始 | 手柄 Menu；1P 键盘 Enter；2P 键盘 T |

双人可使用两只手柄，或第一只手柄加 2P 键盘。双人同时玩、轮流玩或不支持
双人由游戏本身决定。第二只手柄尚未实机测试；已验证两个模拟输入端口互不
干扰、可同时控制内置试玩。

| 玩家 | 移动 | 主要动作 | 其他动作 |
| --- | --- | --- | --- |
| 1P 键盘 | 方向键 | Z / X | C / V，F / G |
| 2P 键盘 | WASD | J / K | U / I，O / L |

默认按实体位置映射：Xbox A → NES B，Xbox B → NES A；手柄面板可交换 A/B。

## 画面和进度

画面支持原始主机比例、整数倍像素缩放、铺满窗口；可切换清晰像素、柔和
显示和 CRT 扫描线。全屏跟随显示器大小缩放，游戏本身仍保持原始分辨率。

返回游戏库或正常退出会保存自动进度，下次启动可继续。卡片右键可从头开始。
手动存档和自动存档分开，游戏的电池存档也会保留。失去窗口焦点或手柄断开时
会暂停。

金手指入口在游戏右上角及暂停菜单。支持按游戏保存代码和启用状态；FC 支持
Game Genie、PAR 和 `地址:数值`。已提供魂斗罗 USA、Super Mario Bros. World
对应版本的预设，默认关闭。没有对应商业 ROM，尚未实测这些预设；已经用自制
卡带验证代码启用、停用和切换。关闭代码后，已修改的生命数等不会自动回退。

所有用户数据位于 `~/Library/Application Support/GameBench/`：

- `library.json`：游戏库、收藏和游玩记录。
- `ROMs/`：导入游戏的本地副本；街机 ZIP 共享 `Arcade` 目录以支持父 ROM。
- `Saves/`：电池存档、手动/自动进度、金手指。
- `BIOS/`：用户补充的 BIOS。设置中可直接打开这些目录。

移除导入的游戏只移除索引，保留游戏和存档文件，以便恢复。

## 开发与验证

需要 Apple Silicon Mac、Xcode Command Line Tools、Python 3。当前机器 SDK 27.2
缺少 SwiftUI 宏插件，构建脚本会优先使用本机已有的 26.5 SDK。

```sh
zsh scripts/build.sh
zsh scripts/test.sh
xcrun clang -dynamiclib -O2 -std=c11 Sources/Core/RetroBridge.c \
  -framework AudioToolbox -o build/libGameBenchTest.dylib
python3 tests/catalog_smoke.py
```

`tests/core_smoke.c` 验证真实核心的视频输出、双人独立/同时输入、存读档、
金手指启停和错误恢复。`tests/library_smoke.swift` 验证 1,000 款嵌套目录导入、
去重和持久化。`tests/catalog_smoke.py` 为每款内置 ROM 启动独立进程，运行
180 帧并检查非空视频帧；开场较慢的游戏最多等待 600 帧。这不等于每一关
都经过完整游玩。

核心使用官方 Libretro Apple Silicon 构建，下载缓存和原始校验值在 `.cache/cores`。
第三方来源、许可和本地游戏包的使用范围见 `THIRD_PARTY.md` 及随附说明。
此预览版在本机进行了临时代码签名，尚未制作面向公开发行的签名安装包。
